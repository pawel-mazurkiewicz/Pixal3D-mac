# Pixal3D backend deps for running under ComfyUI (e.g. ComfyUI-Pixal3D-MPS nodes)
#
# Install these into the SAME Python environment ComfyUI runs with — NOT the
# standalone Pixal3D .venv. The six native Metal externs (cumesh / flex_gemm /
# mtlbvh / mtldiffrast / o_voxel / natten_mps) are built separately, editable,
# into that same env:
#
#   COMFY_PY=/path/to/ComfyUI/.venv/bin/python   # ComfyUI Desktop: <basePath>/.venv
#   "$COMFY_PY" -m pip install -r requirements-comfyui.txt
#   for p in mtlmesh mtlgemm mtlbvh mtldiffrast o_voxel natten-mps; do
#     "$COMFY_PY" -m pip install -e extern/$p --no-build-isolation
#   done
#
# Differs from requirements-mac.txt (the standalone Python 3.10 pin) on purpose:
# - torch / torchvision / numpy / scipy / transformers / safetensors / pillow are
#   OWNED BY COMFYUI and intentionally NOT listed here — pinning them would fight
#   ComfyUI's own stack. (Verified working under ComfyUI's Python 3.12 / torch
#   2.11 / numpy 2.4, which differs from the 3.10 pin's torch 2.12 / numpy 2.2.)
# - gradio / fastapi / uvicorn / starlette (standalone demo server) are omitted.
# - pymeshlab / fast-simplification are omitted: the default native-remesh node
#   path uses the Metal mesh kernels (mtlmesh), not the simplify-sieve fallback.
# - natten-mps and the other Metal externs are NOT listed — they install editable
#   from extern/ (see the loop above), and natten-mps must come from extern/, not
#   the community PyPI package.
#
# Versions below are pinned to a verified-working ComfyUI environment. They will
# no-op for anything ComfyUI already satisfies and add the rest.
